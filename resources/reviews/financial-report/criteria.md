# 财务报告分析评价标准 v1

定性初版，尚未独立校准；不预设分值、权重、损失函数或版本晋升阈值。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 阅读与覆盖 | 完整材料中的关键报表、附注、经营与审计事项纳入任务检查 | 只读三张主表、漏合并范围变化或重大附注 |
| 取数与口径 | 主体、期间、币种、合并范围一致且原值可复核 | 单季累计混用、母公司替代合并、后续重述泄漏 |
| 指标计算 | 可独立重算，分母及平均余额处理合理 | 负基数增长误导、分母零、虚构平均余额 |
| 业绩归因 | 每项主因有证据，区分量价结构及替代解释 | 收入增长被无依据归因为涨价、交互项重复计算 |
| 利润与现金质量 | 同时检验持续性、非经常项目和现金形成机制 | 现金流正即质量高、融资流入当经营回款 |
| 风险与反证 | 重大审计及财务风险、反证和缺失清楚表达 | 重要审计意见遗漏、异常直接定性舞弊 |
| 可用性与状态 | 结论范围、公式、证据和待补信息足够复核 | 单期局部结果冒充完整多期分析 |

`critical`：伪造关键数字/披露，严重数量级或期间错误改变结论，未经证据指称舞弊，使用研究时点后信息造成结论泄漏。`major`：关键附注遗漏、不可比指标比较、实质归因错误、利润现金口径混淆。`minor`：不影响结论但妨碍阅读复核的标签、非关键说明缺失。说明每一问题实际影响，不能只按类别套严重性。

证据不足维度为 uncertain，不能算作通过；真实披露缺失且结果恰当限定时，不将缺资料本身当成执行错误。`not_applicable` 必须以完成全文阅读和无可支持的任务为依据。
