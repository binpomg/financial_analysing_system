# 研报纠错评价标准 v1

定性初版，未经独立校准；不设置数值评分、权重、损失函数或自动晋升阈值。误报和漏报分别记录，不能仅以“找出错误数量多”评价能力。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 全文与主张覆盖 | 正文图表脚注及任务要求主张均纳入检查 | 只查输出已列数字，漏标题或结论错误 |
| 错误真实性 | 已确认问题有直接支持证据或独立计算 | 合理预测/观点被误报、使用事后信息定错 |
| 漏报控制 | 独立检查能发现原文重要错误，未查项有说明 | 明显数量级/主体/引用错误未报 |
| 数字与口径 | 算法、单位、日期、分母、范围准确 | 检查者使用错误口径否定正确原文 |
| 证据与定位 | 报告主张和反证均可回查，引用支持错误判断 | 只有相似文本、缺报告位置或反证 |
| 修正质量 | 最小修正正确且指出必要联动位置 | 修改引入新错、证据不足时编造正确值 |
| 不确定性与状态 | 确认、待核实、观点差异及覆盖限制明确 | 待核实写成确认、没证据宣称全部正确 |

`critical`：捏造证据、将正确关键主张改错并可能改变投资结论、严重错误漏报、历史时点泄漏。`major`：实质误报或漏报、独立计算错误、关键修正不成立、检查覆盖显著不足。`minor`：非关键定位、描述或可执行性问题。严重性要解释影响，不能按错误数机械决定。

缺原始证据本身不证明报告错误；对该项应为 uncertain。报告确有错误但任务材料不可能核实的情况，需要区分材料限制与执行漏报。
