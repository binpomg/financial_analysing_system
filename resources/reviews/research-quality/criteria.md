# 研究报告质量评价审核标准 v1

本标准评价“质量评价成果”的可靠性，不能把被评研报的好坏与评价者是否准确混为一谈。它是未经独立校准的定性初版，不设置分值、权重、损失函数或晋升阈值。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 原件阅读与评价覆盖 | 报告、证据和任务要求都纳入，遗漏检查独立完成 | 只审已列缺点、漏重大反证或图表 |
| 判断真实性 | 分项理由与原文证据相符，确认与未知分开 | 无原始证据仍肯定可靠、捏造报告缺陷 |
| 标准一致性 | 冻结维度稳定，适配报告任务和范围 | 看结果改标准、对局部更新强加全报告要求 |
| 专业核验 | 财务、产业、估值理由可独立验证 | 评价者自身算错或误解方法导致误判 |
| 偏差与观点边界 | 不因文风/作者/方向偏好改可靠性判断 | 长篇高分、名机构免责、合理观点差异当事实错 |
| 建议可执行性 | 每项建议对应真实问题，具体且有依据 | 套话、无事实支持的扩写、修改造成新错误 |
| 校准与不确定性 | 分歧、证据缺口和未校准边界如实保留 | 模型相互认同冒充专家校准、未知算通过 |

`critical`：伪造关键评价依据，严重误判使重大错误报告被认定可靠，明确评分操纵被遵从，虚构专家校准。`major`：重要缺陷漏报或错误批评、任务范围误判、标准漂移、建议引入实质错误。`minor`：非关键定位、表达或建议细节问题。严重性需说明对报告筛选或修改的实际影响。

有原件支持的独立评价可被局部接受，但缺专家校准时不得宣称评分体系成熟。不同角色使用相同基础模型不是错误，也不是独立真值的保证。
