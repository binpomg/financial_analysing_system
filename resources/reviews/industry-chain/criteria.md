# 产业链影响评价标准 v1

本版为未经独立校准的定性标准；不定义数值权重、损失函数或自动升级阈值。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 阅读与事件界定 | 全文覆盖，事件时点、范围和执行阶段正确 | 漏政策豁免/附件，宣布等同落地 |
| 产业关系与公司暴露 | 每个关键节点关系与敞口有依据 | 行业归属代替业务敞口、公司关系虚构 |
| 因果机制 | 前提、方向、时滞、约束明确，相关与因果区分 | 原料价变即认定利润同幅变化 |
| 量化与口径 | 公式可复算，价格/数量/币种口径一致 | 现货价当长协价、同一收益重复加总 |
| 抵消与反证 | 库存、合同、套保、需求等重要因素有处理 | 只挑支持证据、忽略明确相反资料 |
| 不确定性与跟踪 | 假设透明，结论边界和可检验指标清楚 | 无依据精确预测、模糊“持续关注” |
| 证据与状态 | 引用支持完整路径，缺资料与不适用区分 | 未完整阅读判不适用、行业背景冒充完整公司测算 |

`critical`：伪造关键关系、隐藏研究时点泄漏、方向/数量级重大错误导致公司结论相反。`major`：关键传导前提无依据、合同/库存等实质抵消因素遗漏、政策范围误读、重复计量。`minor`：不改变结论但需要修改的路径标签、非关键表述或复核定位问题。严重性说明实际影响。

有机制讨论但缺暴露数据不必认定分析无价值，应判断任务是否要求量化、缺失是否坦诚；关键证据无法核实的维度为 uncertain，不能算通过。
