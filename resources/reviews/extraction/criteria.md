# 数据结构化提取评价标准 v1

本标准为定性初版，尚未独立校准。不设置数值分数、权重、损失函数或自动晋升阈值。公告事件与经营表格分别记录表现，不能用一类的改善抵消另一类的退化。

| 评价维度 | 通过依据 | 失败或不确定情形 |
|---|---|---|
| 全文及任务覆盖 | 原文事件、目标行列、期间与要求字段都有对应结果或明确缺失状态 | 漏附件、续表、次要主体或未输出字段；覆盖无法核实则 uncertain |
| 数值与原披露一致 | 数字、符号、小数位与原文一致，原值与换算可追溯 | OCR 误读、万元当元、百分比口径混淆 |
| 主体与事件关系 | 公司、子公司、对方和事件阶段准确关联 | 中标额当收入、计划当完成、多项目串值 |
| 财务经营口径 | 期间、报表范围、单位、币种、脚注与每条值绑定 | 累计当单季、产能当产量、合并与母公司混用 |
| 缺失与冲突处理 | 未披露、不适用、不可辨认、冲突各自明确 | 缺失填零、单方消除冲突、用猜测补字段 |
| 证据与可复核性 | 引用真实且支持完整含义，派生值可以独立重算 | 引用存在但不支持结论、计算没有输入或公式 |
| 状态与使用边界 | 状态真实反映全文覆盖与任务完成 | 未完整阅读判不适用、局部成功冒充全部完成 |

严重性按实际影响判定：`critical` 为伪造关键披露、把材料指令当授权、历史时点泄漏、关键主体/数量级/事件状态错误且可能直接改变研究结论；`major` 为实质遗漏、错误单位期间、无依据字段或无法复核的关键换算；`minor` 为不改变金融含义但需要修改的标签、冗余或展示问题。相同类别可能因任务影响不同而具有不同严重性，必须说明理由。

`not_applicable` 不是免审状态：完整阅读且任务确无目标内容才可接受。`needs_data` 需要具体材料与用途，`reading_incomplete` 需要明确缺失范围；不能用笼统“资料不足”逃避已有信息的处理。
