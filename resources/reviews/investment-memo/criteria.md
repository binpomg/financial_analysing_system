# 买方投资备忘录评价标准 v1

定性初版，尚未独立校准；不设置数字分值、权重、损失函数、收益门槛或自动晋升阈值。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 任务、时点与覆盖 | 期限、对象、约束和完整资料覆盖明确 | 使用未来信息、单公告冒充公司全研究 |
| 核心事实 | 商业模式与财务经营事实准确且有证据 | 管理层预计当实际、订单直接当收入 |
| 投资论证 | 命题可检验，事实机制假设与价值影响连贯 | 市场空间直接推导回报、叙事替代机制 |
| 预期与估值 | 市场基准和模型有依据，计算时点一致 | 捏造市场共识、无输入精确目标价 |
| 反方与风险 | 重大相反证据和损失机制得到处理 | 忽略明确反证、只有泛化风险套话 |
| 催化与监控 | 事件条件、指标、来源和失效逻辑具体 | 催化日期虚构、跟踪事项与命题无关 |
| 结论与可用性 | 结论强度匹配证据与约束，待补项可执行 | 资料薄弱却确定性买卖/仓位、隐去限制 |

`critical`：捏造关键事实或市场共识、严重估值错误改变投资结论、历史信息泄漏、无授权实施交易。`major`：核心论证不成立、重要反证遗漏、估值/催化依据不足而未说明、实际范围与完成声明不符。`minor`：不改变论证的说明、定位或非关键表达问题。严重性说明具体研究影响。

合理观点差异不等于错误；资料充分性、推理有效性和风险透明度才是评价对象。未来市场涨跌不能单独证明当时研究正确或错误。
