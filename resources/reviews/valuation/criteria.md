# 自动化估值评价标准 v1

定性初版，未独立校准；不预设分数、权重、损失函数、收益目标或自动晋升门槛。

| 维度 | 通过条件 | 主要失败情形 |
|---|---|---|
| 阅读与输入完整性 | 关键输入、附注与市场时点齐全或明确缺失 | 漏受限现金/少数股东、模型默认值隐藏缺项 |
| 方法适用性 | 与行业、盈利阶段和资本结构一致 | 银行机械套用一般工业 FCFF、负盈利强用 PE |
| 事实与假设 | 来源、截止日、管理层指引和分析假设明确区分 | 后续真实业绩回填预测、无来源折现率冒充市场事实 |
| 计算与现金流 | 可独立重算，公式符号与折现口径正确 | FCFF 配股权成本、营运资本符号错、永续增长不低于折现率仍出数 |
| 价值转换 | 企业价值、现金债务、少数股东与股本一致 | 金额单位混用、净债务重复扣除、分子分母归属不一致 |
| 情景与敏感性 | 参数经济含义、内部一致性和结果依赖清楚 | 随意凑区间、概率无依据、多因素变化冒充单因素 |
| 交付可复核性 | 输入公式结果可检查，附件与核算陈述真实 | 宣称已生成或验证不存在的模型、隐去关键限制 |

`critical`：关键数值伪造，重大模型方向/数量级/价值转换错误，历史信息泄漏，虚构已核算附件。`major`：重要输入或调整遗漏、假设无依据且未标注、方法不适用、情景或公式不可复核。`minor`：不改变估值含义但需要修订的说明、标签或非关键展示问题。每项严重性根据影响解释。

估值是条件性结果；审核不以未来股价是否接近模型值判定模型正确。资料不足时诚实交付局部模型不是失败，但未经说明将其当作完整估值是失败。
